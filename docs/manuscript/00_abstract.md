# Abstract

An induced path in a hypercube crosses a single edge at each step and contains
no edges between nonconsecutive vertices. This paper describes the Python
search implementation and checks its output in bounded experiments. Small
searches regenerate three paths, an independent adjacency test verifies each
path, and the package validates retained sequences in higher dimensions.
The experiment records both fresh search output and lengths recovered from
stored sequences so each result can be traced to its source.
