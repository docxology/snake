# snake_in_box — Core Python Package

Implementation of the N-dimensional snake-in-the-box search (pruned BFS, priming, benchmarks, analysis, visualization). Install with `pip install -e .` from the repo root; see root `README.md`.

**Agent guidance:** see `AGENTS.md` in this directory and in `analysis/`, `benchmarks/`, `core/`, `search/`, `utils/` (authoritative module docs — not duplicated here).

Subpackages: `core/`, `search/`, `analysis/`, `benchmarks/`, `utils/`, plus `examples/`, `scripts/`, `tests/`.
