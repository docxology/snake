# Snake-in-the-Box

Find and validate induced paths in the edge graph of a hypercube. The Python package
implements the pruned breadth-first search strategy described by Thomas E. Ace.

- [Get started](docs/getting-started.md) with a three-dimensional search and validation.
- [Read the documentation](docs/index.md) for the algorithms, API, and examples.
- [Build the methods manuscript](docs/manuscript/README.md) from a fresh search and retained path data.
- [Read the reference publication](docs/reference/ace-2025.pdf) by Thomas E. Ace. [Zenodo](https://doi.org/10.5281/zenodo.17538015)
